# Anime Slime v1.0.0

تطبيق Android مفتوح المصدر لمشاهدة الأنمي، بواجهة عربية RTL وتصميم داكن. التطبيق لا يضم حلقات أو مصدرًا مدمجًا؛ يضيف المستخدم المستودعات والمصادر، وهو مسؤول عن الثقة بها وقانونية استخدامها.

## الوظائف

يحتوي الإصدار على قاعدة Room للأعمال والحلقات والتاريخ والتنزيلات والمستودعات والتتبّع، وDataStore للإعدادات، وHilt، وWorkManager، وMedia3 ExoPlayer، وCoil، وواجهات Compose.

يمكن للمستخدم البحث في Animelek، فتح تفاصيل العمل والحلقات، تشغيل روابط الفيديو التي يعيدها المصدر، إضافة المستودعات والتحقق منها وتحديثها وتعطيلها وحذفها، وتنزيل الملفات مع التقدم وإعادة المحاولة. أضيف المستودع المطلوب `https://raw.githubusercontent.com/yuzono/anime-repo/repo/index.min.json` ومصدر Animelek المستقل عند أول تشغيل.

المشغل يدعم MediaSession وPicture-in-Picture والقفز المزدوج والسرعة والقفل. الإعدادات الحية تحفظ خيارات المشغل والتنزيلات والإشعارات في DataStore. النسخ الاحتياطي والاستعادة متاحان من واجهة Storage Access Framework. توجد خدمات AniList GraphQL وMAL OAuth2 لتحديث التقدم عندما يزوّد المستخدم إعدادات OAuth والتوكن محليًا.

## البناء والاختبار

```bash
./gradlew :app:assembleDebug :app:testDebugUnitTest
./gradlew :app:assembleRelease
```

الحد الأدنى Android 8 / API 26. لا تُخزّن مفاتيح OAuth أو مفاتيح التوقيع في GitHub. يقرأ التكامل المستقبلي القيم من `local.properties` أو من إعدادات CI السرية.

## المصادر والإضافات

توافق Aniyomi الكامل غير مدّعى؛ التطبيق يستخدم محوّلات مصدر آمنة تعيد الأعمال والحلقات وروابط الفيديو. راجع [docs/extensions.md](docs/extensions.md).

## إخلاء المسؤولية

المستخدم مسؤول عن المستودعات والمصادر والمحتوى الذي يضيفه.
