# مصادر Anime Slime

## محولات فعلية مضافة

- Animelek: `https://animelek.cc/home`
- WitAnime: `https://witanime.site/`
- Donghua-Ar: `https://donghua-ar.me/` (يستخدم tRPC API العام في الموقع)

تستخدم النتائج عقد `CatalogSource` الموحد، ويحدد كل عمل `sourceId` حتى يمكن فتح التفاصيل بالمحول الصحيح.

## مصادر مؤجلة

- Anime3rb
- Animerco / EVA
- Anime4up

هذه المواقع أعادت Cloudflare challenge من بيئة البناء أثناء الفحص. لم تتم إضافة محول يدّعي نجاحًا زائفًا؛ ستحتاج هذه المواقع إلى مصدر API رسمي أو WebView/حل تكامل منفصل إذا كان مسموحًا من الموقع.
