# واجهة المصادر والإضافات

## التنفيذ الحالي

- طبقة `RepositoryService` تجلب `index.min.json` عبر HTTP(S) بمهلة 15/25 ثانية وتتحقق من كود HTTP وصيغة JSON ووجود إضافات صالحة.
- المستودع المطلوب `https://raw.githubusercontent.com/yuzono/anime-repo/repo/index.min.json` يُضاف عند أول تشغيل.
- مصدر Animelek المستقل `https://animelek.cc/home/` يُضاف كـ source منفصل، ولا يُعامل كفهرس إضافات.
- المستودعات محفوظة في Room ويمكن تفعيلها وتعطيلها وتحديثها وحذفها من شاشة التصفح.
- يوجد WorkManager لتحديث المستودعات دوريًا عند توفر الاتصال.

## توافق Aniyomi

صيغة `extensions-lib` الكاملة تحتاج تشغيل كود الإضافة الخاص بكل مصدر، وهو غير آمن داخل عملية التطبيق ولا يمكن اعتباره متوافقًا بمجرد قراءة الفهرس. لذلك يستخدم المشروع **واجهة مصدر موحّدة آمنة**: بحث، أحدث، تفاصيل، حلقات وروابط فيديو؛ وتحتاج كل إضافة إلى محوّل مصدر يخرج هذه النماذج. لا ندّعي توافقًا كاملًا مع إضافات Aniyomi، وهذا مقصود وموثق.

## المسؤولية

الإضافات والمصادر خارجية. المستخدم مسؤول عن الثقة بالمستودع، وقانونية المحتوى والروابط التي يضيفها.
