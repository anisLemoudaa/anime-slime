# Anime Slime

تطبيق أندرويد مفتوح المصدر لمشاهدة الأنمي، بواجهة عربية RTL وتصميم داكن مستوحى من `design/anime-slime.html`.

> **تنبيه:** التطبيق لا يضم محتوى أو مصدرًا مدمجًا. يضيف المستخدم مستودعات ومصادر بنفسه، وهو مسؤول عن قانونية المحتوى والروابط التي يضيفها.

## الحالة الحالية — المرحلة 1

تم تنفيذ الهيكل الأولي القابل للبناء باستخدام Kotlin وJetpack Compose وMaterial 3:

- ثيم داكن بالألوان `#07090F` و`#111726` وتدرج السماوي/الأزرق.
- اتجاه عربي RTL وشريط تنقل سفلي عائم من خمسة تبويبات.
- شاشات أولية: الرئيسية، المكتبة، التحديثات، التصفح، المزيد، الإعدادات، تفاصيل العمل.
- أزرار وتنقلات فعلية وحالات عرض أولية للحلقات والمكتبة والمصادر.
- الشعار المرفق محفوظ داخل `app/src/main/res/drawable/anime_slime_logo.png`.
- المرجع البصري محفوظ داخل `design/anime-slime.html`.

## البناء

يتطلب Android Studio حديثًا أو Gradle 8.10.2 وJDK 17+. افتح المشروع ثم نفّذ:

```bash
./gradlew :app:assembleDebug
```

الحد الأدنى Android 8 / API 26.

## خارطة الطريق

سيتم تنفيذ المراحل التالية بــ commits مستقلة: قاعدة البيانات، المستودعات والإضافات، التصفح والبحث، المكتبة والتفاصيل، Media3، التنزيلات، التحديثات والإشعارات، الإعدادات، التتبع، النسخ الاحتياطي، الاختبارات وCI.

## المصادر والإضافات

سيكون دعم المستودعات والإضافات من خلال فهرس JSON يضيفه المستخدم. لا يتم تضمين أي مفاتيح سرية. مصدر الفهرس المطلوب من المستخدم سيضاف في مرحلة المستودعات بعد التحقق من صيغته واتصاله.
