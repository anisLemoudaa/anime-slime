# واجهة المصادر والإضافات

## الوضع الحالي

المرحلة الأولى تعرض واجهة التصفح ومصادر تجريبية فقط؛ لم تُنفّذ بعد عمليات الشبكة أو تثبيت الإضافات.

## الخطة

ستدعم طبقة البيانات مستودعات تشير إلى `index.min.json` عبر HTTP(S)، مع التحقق من الرابط والـ JSON والحقول المطلوبة، ثم عرض اسم المستودع وعدد الإضافات قبل الحفظ.

سيكون لكل مصدر واجهة: الأحدث، الشائع، البحث، تفاصيل العمل، الحلقات وروابط الفيديو. تُعزل الإضافة عن بقية التطبيق ولا تُمنح أسرارًا أو صلاحيات غير لازمة.

دعم صيغة Aniyomi/extensions-lib سيُقيّم في مرحلة المستودعات. إذا تعذر التوافق الكامل، ستُستخدم محوّلات بسيطة موثقة بدل الادعاء بالتوافق.

المستخدم مسؤول عن المستودعات والإضافات ومحتواها وقانونية استخدامها.
