# مشغلات Anime Slime

يستخدم التطبيق مسارين واضحين للتشغيل. الروابط المباشرة مثل MP4 وMKV وHLS (`m3u8`) تمر عبر Media3/ExoPlayer، مع دعم أزرار التشغيل الأصلية، التقديم والتأخير عشر ثوانٍ، السرعة، القفل، double-tap، MediaSession، حالة التحميل، رسالة الخطأ وإعادة المحاولة. أضيفت وحدة Media3 HLS حتى لا تظهر قوائم m3u8 كشاشة فارغة.

أما روابط صفحات المشاهدة وiframe مثل Filemoon فتُفتح في WebView مستقل يدعم JavaScript وDOM storage وتشغيل الوسائط بلا نقرة إضافية، مع شريط رجوع، زر رجوع النظام، وحالة تحميل. لا يحاول Media3 تشغيل HTML أو iframe كرابط ملف.

إذا فشل ملف مباشر، يعرض المشغل سبب الفشل وزر إعادة المحاولة بدل البقاء في شاشة سوداء صامتة.
