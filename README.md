# Anime Slime

تطبيق Android مفتوح المصدر لمشاهدة الأنمي، بواجهة عربية RTL وتصميم داكن. التطبيق **مشغّل ومخزن محلي فقط** ولا يضم محتوى أو مصدرًا مدمجًا؛ يضيف المستخدم المستودعات والمصادر، وهو مسؤول عن الثقة بها وقانونية استخدامها.

## ما تم تنفيذه

- Kotlin + Jetpack Compose + Material 3 + Navigation Compose.
- Clean Architecture أولية بطبقات `data` و`ui` وواجهات DAO/ViewModel بحالة قابلة للمراقبة.
- Room لنماذج الأعمال والحلقات والمكتبة والتاريخ والتنزيلات والمستودعات والإضافات والتتبّع.
- DataStore لإعدادات المظهر والمشغّل والخصوصية.
- مستودعات HTTP/JSON مع تحقق ومهلة وأخطاء عربية، وواجهة إضافة/تحديث/تعطيل/حذف.
- إضافة تلقائية للمستودع المطلوب ومصدر Animelek المستقل عند أول تشغيل.
- WorkManager لتحديث المستودعات دوريًا عند توفر الشبكة.
- DownloadWorker بطابور وتنزيل إلى مساحة التطبيق وتقدم وحالات فشل/إعادة محاولة.
- BackupManager لنسخة JSON مضغوطة عبر Storage Access Framework.
- Media3 ExoPlayer component جاهز لتشغيل رابط الفيديو الذي يخرجه المصدر وحفظ التقدم عبر نموذج Episode.
- اختبارات محلل فهرس، وGitHub Actions للبناء والـlint والاختبارات ورفع APK.

## البناء والنشر

افتح المشروع في Android Studio، ثبّت Android SDK 35، ثم:

```bash
./gradlew testDebugUnitTest lintDebug assembleDebug
```

الحد الأدنى Android 8 / API 26. لا توجد مفاتيح سرية داخل الكود؛ أي OAuth مستقبلي يقرأ من `local.properties`.

## الحالة

الواجهات الأساسية موجودة، وطبقة البيانات والمستودعات والتنزيل والنسخ الاحتياطي قيد الربط التدريجي بالشاشات. دعم Aniyomi الكامل غير مدّعى؛ راجع [docs/extensions.md](docs/extensions.md).

## إخلاء المسؤولية

المستخدم مسؤول عن المستودعات والمصادر والمحتوى الذي يضيفه. لا يوزع المشروع حلقات أو روابط مشاهدة مدمجة.
