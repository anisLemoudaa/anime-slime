# نظام التنزيلات

تُحفظ كل عملية تنزيل في `DownloadItem` مع رابط المصدر وحالتها وتقدمها ومسار الملف. عند بدء التنزيل يتم إنشاء `Episode` حقيقي داخل Room وربطه بالعمل، ثم تُضاف المهمة إلى WorkManager بطابور فريد لكل حلقة.

يستخدم العامل HTTP Range إذا كان الملف الجزئي موجودًا، ويضيف البيانات إلى الملف بدل البدء من الصفر. وإذا تجاهل الخادم Range يعيد العامل إنشاء الملف بأمان. حالات القائمة هي: `QUEUED` و`RUNNING` و`PAUSED` و`CANCELLED` و`FAILED` و`COMPLETED`.

زر التنزيل يظهر فقط عندما يعيد الـResolver رابط ملف مباشرًا مثل MP4 أو MKV. صفحات المشاهدة وملفات iframe لا تُنزّل كأنها فيديو؛ بل تبقى للتشغيل عبر WebView. شاشة التنزيلات متاحة من تبويب المزيد، وتعرض التقدم، المسار، الخطأ، الإيقاف، الاستئناف والحذف.
